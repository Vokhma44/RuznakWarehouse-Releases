# РУЗНАК Склад — APK-релизы

Официальный канал обновлений Android-приложения **РУЗНАК Склад**.

- Исходный код здесь не публикуется.
- Подписанные APK размещаются в разделе **Releases**.
- Файл `latest.json` используется приложением для проверки новой версии.
- Release APK имеет пакет `ru.ruznak.warehouse` и подписывается постоянным ключом РУЗНАК.

Первый стабильный APK будет опубликован после настройки защищённых GitHub Actions Secrets.
